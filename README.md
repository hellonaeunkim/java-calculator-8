# java-calculator-precourse

## 구현할 기능 목록

### 1. 입력 처리

- 사용자로부터 문자열을 입력받는다.
- 입력값이 빈 문자열("")일 경우 0을 반환한다.
- 입력 값이 null인 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

### 2. 구분자 처리

- 기본 구분자(쉼표 `,`, 콜론 `:`)로 문자열을 분리한다.
- 커스텀 구분자가 지정된 경우(`//[구분자]\n`) 해당 구분자를 사용해 분리한다.
    - 예: `//;\n1;2;3` → 구분자는 `;`

### 3. 숫자 추출 및 검증

- 분리된 문자열을 정수로 변환한다.
- 음수 또는 숫자가 아닌 값이 존재하면 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

### 4. 합산 로직

- 검증된 숫자들의 합을 계산한다.

### 5. 출력 처리

- 계산 결과를 `결과 : [숫자]` 형식으로 출력한다.
